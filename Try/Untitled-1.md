**问题描述**
网络管理员负责管理一个大型网络。该网络由 N 台计算机和 M 条连接计算机对之间的链路组成。任意两台计算机之间都可通过一系列链路直接或间接相连，因此数据可以在任意两台计算机之间传输。管理员发现，某些链路对网络至关重要，因为一旦其中任意一条链路失效，就会导致部分计算机之间无法传输数据。他将这类链路称为“桥”。他计划逐个添加新的链路，以消除所有桥。
你的任务是帮助管理员，在每次添加新链路后，报告当前网络中桥的数量。

**输入**
输入包含多个测试用例。每个测试用例以一行两个整数 N（1 ≤ N ≤ 100,000）和 M（N - 1 ≤ M ≤ 200,000）开始。  
接下来的 M 行，每行包含两个整数 A 和 B（1 ≤ A ≠ B ≤ N），表示计算机 A 与 B 之间有一条连接。计算机编号从 1 到 N。保证初始网络中任意两台计算机都是连通的。  
下一行包含一个整数 Q（1 ≤ Q ≤ 1,000），表示管理员计划依次向网络中添加的新连接数量。  
接下来的 Q 行中，第 i 行包含两个整数 A 和 B（1 ≤ A ≠ B ≤ N），表示第 i 条新添加的连接，将计算机 A 与 B 连接起来。
最后一个测试用例之后是一行包含两个零的数字。

**输出**
对于每个测试用例，输出一行包含测试用例编号（从1开始），然后输出Q行，第i行包含一个整数，表示在添加前i条新连接后网络中的桥的数量。每个测试用例的输出后打印一个空行。

**Sample Input**
```
3 2
1 2
2 3
2
1 2
1 3
4 4
1 2
2 1
2 3
1 4
2
1 2
3 4
0 0
```
 

**Sample Output**
```
Case 1:
1
0

Case 2:
2
0
```
